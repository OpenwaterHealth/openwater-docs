# System Requirements

## Software Requirements

- Python 3.9 or higher
- pip 21.0 or higher
- Git 2.30 or higher

## Hardware Requirements

- 4GB RAM minimum (8GB recommended)
- 2GB free disk space
- USB port for hardware connectivity (optional)

## Supported Platforms

- Linux (Ubuntu 20.04+, RHEL 8+)
- macOS 11+ (Big Sur and later)
- Windows 11

!!! note "Platform update (October 2026)"
    Windows 11 is now the only supported Windows version for Open-MOTION and Open-LIFU. Microsoft ended Windows 10 support in October 2025. Current releases may still run on Windows 10, but we no longer test there or fix Windows 10–only issues. If you're on Windows 10, upgrade to Windows 11 or use Linux. [Read the announcement](https://github.com/orgs/OpenwaterHealth/discussions/331).
